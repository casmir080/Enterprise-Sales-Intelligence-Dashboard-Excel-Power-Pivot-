Project Title

Enterprise Sales Intelligence Dashboard (Excel + Power Pivot)

OvervieW

This project showcases an interactive Excel dashboard designed for enterprise-level sales analysis. Using Power Query, Power Pivot, and DAX, the dashboard delivers insights across time, region, and product categories. The structure and visuals mirror real business reporting tools used by decision-makers.

Project Features Data model built using relationships between Sales, Products, Customers, and Calendar tables Dynamic PivotTables and interactive charts Slicers for filtering by Year, Region, and Product Category Custom DAX measures for advanced KPI tracking Clean and business-ready visual layout using Excel shapes and design formatting

Tables Used SalesData — Contains sales transactions including dates, product IDs, customer IDs, quantity, and amount Products — Contains product names, IDs, prices, and categories Customers — Contains customer IDs, region, and segment data Calendar — A complete calendar table with Date, Month, and Year columns

Key DAX Measures Total Sales Total Quantity Sold Sales YTD Sales Last Year YoY Growth Percentage Product Rank by Sales

Insights Delivered Monthly sales trends for performance tracking Regional sales distribution Top-performing product categories Year-over-year growth comparison

Tools and Technologies Microsoft Excel Power Query Power Pivot DAX PivotTables and Slicers Simulated sales dataset with over 1,000 rows.
